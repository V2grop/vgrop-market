# مدیریت بنر بالای برنامه — نسخه ۰٫۱۵٫۱

فایل [config/announcement.json](../config/announcement.json) در شاخه `main` همین مخزن را ویرایش و Commit کنید. نصب مجدد APK لازم نیست. برای اولین استفاده، کاربر باید نسخه ۰٫۱۵٫۱ یا جدیدتر را نصب کند.

1. `enabled` را از `false` به `true` تغییر دهید.
2. `title` عنوان (حداکثر ۸۰ نویسه) و `text` متن (حداکثر ۳۶۰ نویسه) است.
3. `url` لینک HTTPS و `button` نوشته دکمه است. برای پیام بدون لینک، هر دو را خالی بگذارید.
4. برای هر پیام تازه، `id` جدید بگذارید؛ مثلاً `notice-002`. کاربری که پیام قبلی را بسته، پیام با شناسه جدید را می‌بیند.
5. برای مخفی‌کردن بنر، `enabled: false` را ذخیره کنید. در حالت خاموش، بنر هیچ فضای خالی ندارد.

نمونه:

```json
{
  "schema_version": 1,
  "enabled": true,
  "id": "notice-002",
  "title": "خبرهای VGrop Market",
  "text": "برای دریافت نسخه‌های تازه، به کانال ما سر بزنید.",
  "button": "ورود به کانال",
  "url": "https://t.me/V2grop",
  "starts_at": 0,
  "ends_at": 0
}
```

`starts_at` و `ends_at` اختیاری‌اند؛ زمان Unix برحسب ثانیه UTC، و صفر یعنی بدون محدودیت زمان. بنر فقط متن ساده است و HTML اجرا نمی‌کند. JSON خراب یا لینک ناامن باعث مخفی‌شدن بنر می‌شود. متن این فایل عمومی است؛ رمز یا توکن در آن نگذارید.

اپ هنگام ورود و سپس هر ۱۵ دقیقه در پیش‌زمینه فایل را می‌گیرد. کش GitHub و اتصال اینترنت ممکن است نمایش تغییر را به تأخیر بیندازد. در قطع اینترنت، آخرین پیام معتبر حداکثر ۲۴ ساعت می‌ماند؛ تاریخ پایان زودتر اعمال می‌شود. حذف فایل نیز در اولین دریافت موفق آن را مخفی می‌کند. ساعت دستگاه باید صحیح باشد. فرمان مخفی‌سازی روی دستگاه آفلاین فوری نیست.

هیچ SDK تبلیغاتی، ردیاب، دریافت توکن GitHub یا کد قابل‌اجرا اضافه نشده است. درخواست HTTPS مستقیم به GitHub ارسال می‌شود؛ نشانی IP طبق عملکرد عادی HTTP برای میزبان قابل مشاهده است. تغییر بنر فقط با دسترسی نوشتن به مخزن امکان‌پذیر است. تغییر فایل تنظیمات به‌تنهایی بیلد جدید ایجاد نمی‌کند.

## جابه‌جایی دیده‌بان

بدنه ردیف ارز را نگه دارید و بالا یا پایین بکشید. ردیف کنار لبه فهرست به‌صورت خودکار اسکرول می‌شود. ترتیب با هر جابه‌جایی ذخیره می‌شود. لمس کوتاه همچنان تحلیل را باز می‌کند؛ ستاره برای حذف/افزودن باقی است. در TalkBack، عملیات «انتقال به جایگاه بالاتر/پایین‌تر» جایگزین کشیدن است؛ دکمه‌های فلش از ظاهر حذف شده‌اند.
