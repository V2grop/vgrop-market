# سرور اختیاری هوش مصنوعی

این پوشه برای تحلیل معمولی اپ 0.3 لازم نیست. فقط اگر دستیار مدل زبانی می‌خواهید آن را نصب کنید.

Python 3.11+؛ بدون کتابخانه خارجی:
```bash
cd backend
cp .env.example .env
python3 -c 'import secrets; print(secrets.token_urlsafe(32))'
```
توکن تولیدشده را در APP_TOKEN بگذارید. OPENAI_API_KEY را با کلید خود و OPENAI_MODEL را با نام مدل در دسترس حسابتان تنظیم کنید. کلید را در اپ وارد نکنید.
```bash
chmod 600 .env
./start.sh
```
سرور روی 127.0.0.1:8080 گوش می‌دهد. با پراکسی HTTPS در دسترس گوشی قرار دهید؛ Caddyfile.example نمونه است. برای اجرای دائمی از مدیر سرویس سیستم استفاده کنید. در اپ، دستیار اختیاری را روشن و نشانی HTTPS و APP_TOKEN را ثبت کنید.

تغییر حساب: کلید داخل .env را عوض و سرور را بازراه‌اندازی کنید. سابقه پاسخ‌ها در pulse.sqlite3 حفظ می‌شود. AI_DAILY_REQUEST_LIMIT سقف تعداد درخواست در ۲۴ ساعت لغزان است، نه سقف دقیق هزینه. اشتراک ChatGPT به‌تنهایی هزینه API را پوشش نمی‌دهد.

آزمایش اتصال تنها وجود تنظیمات مدل را بررسی می‌کند. اعتبار کلید با درخواست واقعی مشخص می‌شود. داده‌های تحلیل سرور مستقل از گزارش محلی دوباره دریافت می‌شوند.

این سرور نمونه تک‌کاربره است؛ برای انتشار عمومی به احراز هویت چندکاربره، محدودیت نرخ، نظارت و پشتیبان‌گیری نیاز دارد. هیچ سروری با این فایل نصب به‌صورت خودکار مستقر نمی‌شود.
