# VGrop Market 0.14.1 — searchable markets

- Added a prominent search field to **All Markets**.
- Search accepts symbols, pairs and common Persian/English names, including `BTC`, `BTC/USDT`, `Bitcoin` and `بیت‌کوین`.
- Added live result count, one-tap clear and an explicit empty-result message.
- Kept watchlist add/remove directly on every filtered result.
- Retained the adaptive research style, multi-horizon scenario bars, live price, galaxy UI and optional backend architecture from 0.14.0.

IMPORTANT: Scenario scores are experimental research weights, not statistically validated trading probabilities or financial advice. The included BTC 4h diagnostic did not beat its past-frequency baseline. This APK uses a public compatibility testing key and is not a production-signed Play Store build.
